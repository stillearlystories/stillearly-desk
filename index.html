StillEarly Desk

One job: get our finished videos into our own TikTok inbox.

StillEarly Desk is an internal tool used by StillEarly, the operator of the StillEarly channel. It uploads the channel's own finished videos to the channel's own TikTok inbox as drafts. Nothing is published by this tool. The creator reviews each draft inside TikTok and publishes it there, in TikTok's own flow, only when it is ready.

How it works

1. Finish the video. The StillEarly creator finishes a video outside this tool, the same way every StillEarly video is made.

2. Sign in once. The operator signs in with the channel's own TikTok account and approves the two permissions listed below.

3. Upload as a draft. The tool sends the finished video file to the account's TikTok inbox as a draft, using TikTok's official Content Posting API.

4. Review and publish in TikTok. The creator opens the draft in TikTok, checks it, adds the final touches, and publishes it in TikTok itself.

Who it is for

StillEarly Desk is a private, single operator tool. It is built and run by StillEarly for StillEarly's own channel work. There are no public accounts, no sign up for anyone else, and no service offered to third parties. If you are not the StillEarly operator, there is nothing here for you to use, and that is by design. This website exists so that anyone reviewing the tool, including TikTok, can see plainly what it does and how it treats data.

What it accesses, and nothing more

The tool asks TikTok for exactly two permissions, and only for the operator's own account:

user.info.basic: basic information about the operator's own TikTok account, so the tool can confirm it is connected to the right account before uploading.

video.upload: permission to upload a video file the operator chooses to the operator's own TikTok inbox, where it arrives as a draft.

The tool does not post directly, does not read other people's accounts or content, and does not collect followers, comments, messages, or viewing data. It runs no tracking and no advertising, and no data is ever sold. The full detail is in the Privacy Policy.
