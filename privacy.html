Privacy Policy

StillEarly Desk. Last updated: November 25, 2026.

1. The short version

StillEarly Desk is an internal tool with one operator. It touches only the operator's own TikTok account and the operator's own video files. It collects nothing from third parties, sells nothing, shares nothing for marketing, and runs no tracking. The rest of this page gives the full detail.

2. Who this policy covers

This policy covers the StillEarly Desk tool and this website. The only person whose data the tool handles is the operator, the person who runs the StillEarly channel. There are no third party users whose data could be collected.

3. Data the tool accesses

TikTok account basics, through user.info.basic: when the operator signs in, TikTok returns basic information about the operator's own account, such as the account identifier, display name, and avatar. The tool uses this only to confirm which account it is connected to before an upload. Video files, through video.upload: the tool sends the video files the operator selects to the operator's own TikTok inbox, where they arrive as drafts. The tool does not keep copies of video files for any other purpose. Access tokens: TikTok issues access tokens when the operator approves the connection. The tool stores those tokens so the operator does not have to sign in again for every upload. Section 6 explains how they are kept.

4. Data the tool does not collect

No data about other TikTok users, including followers, viewers, or commenters. No comments, messages, likes, or watch history. No location data, contacts, or device identifiers. No analytics, advertising identifiers, or tracking of any kind. This website sets no tracking cookies and runs no third party analytics.

5. How the data is used

The data above is used for one purpose only: to confirm the operator is connected to the correct TikTok account; and to upload the operator's chosen video files to that account's TikTok inbox as drafts. It is not used for profiling, advertising, research on other people, or any other purpose.

6. Storage and security

Access tokens are stored securely, with access limited to the operator and the tool itself. Tokens are kept only while the operator continues to use the tool. Video files pass through the tool for the upload and are delivered to TikTok; the tool is not a storage service and does not build an archive of uploads. Reasonable care is taken to protect stored tokens, though no storage method can be guaranteed perfectly secure.

7. Sharing and selling data

No data is sold, ever. No data is shared with advertisers, data brokers, or other third parties for their own use. The only transfer that happens is the one the tool exists to make: account authorization and video files are sent to TikTok, through TikTok's official API, at the operator's direction.

8. Revoking access and deletion

The operator can revoke the tool's access at any time in TikTok's own settings, which stops the tokens from working. The operator can also write to the contact address below and ask for any stored tokens or account information held for the tool to be deleted, and StillEarly will delete them.

9. This website

This website is a set of plain informational pages. It has no accounts, no sign in, and no forms. Reading it sends no personal information to StillEarly. If the operator or a reviewer chooses to send an email, that email is used only to reply to the question it raises.

10. Changes to this policy

If the tool's data practices change, this page will be updated first, and the date at the top of the page will change with it. The tool will not start collecting a new kind of data under an old version of this policy.

11. Contact

Questions about this policy, or a deletion request, go to StillEarly at stillearlystories@gmail.com.
